= Protect production tags from overwrite
:context: protect_image_tags_with_immutability_policies

[role="_abstract"]

To keep production {productname} tags unchanged, you can set immutability policies. Immutable tags cannot be overwritten and are excluded from auto-prune, but you can still retire them with per-tag expiration.

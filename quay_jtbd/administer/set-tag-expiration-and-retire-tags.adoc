= Retire image tags on a schedule
:context: set_tag_expiration_and_retire_tags

[role="_abstract"]

When stale tags must not live forever, I want to set tag expiration and delete or undo tags, so that we can retire content on a schedule without relying only on auto-prune. Per-tag expiration, including the `quay.expires-after` label or annotation, still applies to immutable tags. Auto-prune does not.
